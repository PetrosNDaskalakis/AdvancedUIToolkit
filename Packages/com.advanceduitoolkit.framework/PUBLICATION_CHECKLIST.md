# Public GitHub / open-source release checklist

**DO NOT PUBLISH YET.** This archive deliberately contains **no open-source license** until the legal owner chooses one.

- [ ] Confirm the employer/company owns or permits publication of all contributed code.
- [ ] Verify no MNW source, scenes, textures, prefabs, branding, licensed font files, or confidential material is present.
- [ ] Check all transitive or copied code origins and licenses (including snippets and AI-assisted code as applicable to company policy).
- [ ] Choose an explicit license and add its complete text (`LICENSE.md`), plus any required third-party notices.
- [ ] Approve the project name, GitHub namespace/organization, and repository visibility.
- [ ] Confirm the package compiles and passes automated/manual tests in a **clean Unity project**.
- [ ] Remove personal paths, secrets, tokens, and internal URLs from Git history and documentation.
- [ ] Decide issue triage, contribution workflow, versioning, and release tagging.
- [ ] Once approved, publish the repository and create a version tag (e.g. v1.0.0 (only after release gates)).

This package has been statically reviewed for obvious game-specific assembly references; **this is not a legal or complete security audit**.
